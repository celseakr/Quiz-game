# Quiz Game

An interactive quiz game built with HTML, CSS, and JavaScript.

## 🌟 Features

- Multiple-choice quiz questions
- Interactive answer selection
- Score tracking
- Immediate feedback
- Restart quiz functionality

## 🛠️ Technologies

- HTML
- CSS
- JavaScript

## 🚀 How to Run

Open `index.html` in a web browser.
